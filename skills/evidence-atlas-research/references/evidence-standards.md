# Evidence standards

## Evidence labels

| Label | Use when | Allowed wording |
|---|---|---|
| Confirmed | A primary source or direct observation establishes the claim | “The manual specifies…” / “The teardown shows…” |
| Patent embodiment | The feature appears in a patent disclosure | “The patent depicts…” |
| Secondary report | A credible article reports the point but primary evidence is absent | “The publication reports…” |
| Inference | Multiple clues support a mapping that is not explicitly confirmed | “This likely corresponds to…” |

Never collapse these categories into a single statement of fact.

## Figure authenticity

- Record the source URL, document identifier, page, figure number, and access date.
- Keep an untouched source PDF or image alongside working crops when possible.
- Crop only margins or irrelevant neighboring content. Do not erase reference numerals, arrows, legends, scale bars, watermarks, or copyright notices.
- If contrast or sharpness is adjusted, say so when it could affect interpretation.
- Do not place newly drawn arrows inside an original figure unless clearly styled and disclosed as an editorial annotation. Prefer a caption that says where to look.
- Never present an AI-generated, traced, or reconstructed image as a patent, paper, or teardown figure.
- Call an extracted raster **图纸页 N** when it contains multiple original figures or when the extraction index is not identical to the patent's official figure number.

## Annotation separation

- **图示** may name only what the source text or visible drawing supports.
- **运动/作用** must state the kinematic or functional relation supported by the source. If none is shown, say so explicitly.
- **样机借鉴** is an engineering recommendation and must never be phrased as part of the patent disclosure.
- Do not infer a motor, seal, spring, sensor, or load path merely because a shape resembles one.
- Label unrelated payloads or accessories as non-core instead of inventing relevance to the mechanism under study.

## Patent discipline

- Identify jurisdiction, publication number, priority date, applicant/assignee, inventors, and family relationships.
- Read the detailed description around the cited figure; drawings alone are not enough.
- Distinguish application publication, granted patent, and legal status.
- Treat claims as legal boundaries and embodiments as disclosed examples; neither alone proves commercial implementation.

## Paper and teardown discipline

- For papers, record DOI or stable repository URL and preserve the original caption.
- For teardown imagery, record the exact product/model and photographer/publication.
- If the teardown is a related model, label the relationship on the same page as the photo.
- Use secondary images only when they add direct physical evidence unavailable from primary documents.

## Copyright-aware delivery

Use only the figures needed for analysis, keep attribution close, avoid reproducing an entire copyrighted work, and link to the original. Patent-office drawings are usually the safest visual backbone, but jurisdiction-specific rules and site terms still apply.
